# gigavuecore_load_mobility_gtp_node_configs Data Source

Load mobility gtp node configurations by alias

## Example Usage

```terraform
data "gigavuecore_load_mobility_gtp_node_configs" "example" {
  cpnode_alias   = "example"
  gtpnode_alias  = "example"
  solution_alias = "example"
}
```

## Schema

### Arguments

The following arguments are supported:

* `cpnode_alias` (String, required) - Alias of the control node
* `gtpnode_alias` (String, required) - Alias of the gtp node
* `solution_alias` (String, required) - Alias of the configured solution

### Attributes

In addition to all arguments above, the following attributes are exported:

* `alias` (String, computed) - Alias of the GTP node
* `collector_tool_config` (Attributes, computed) (see [below for nested schema](#nestedatt--collector_tool_config))
* `control_metadata_ip_interface_config` (Attributes, computed) (see [below for nested schema](#nestedatt--control_metadata_ip_interface_config))
* `control_sam_exporter_node_configs` (Attributes List, computed) (see [below for nested schema](#nestedatt--control_sam_exporter_node_configs))
* `gs_group_config` (Attributes, computed) - GigaSMART Port group (see [below for nested schema](#nestedatt--gs_group_config))
* `gsop_configs` (Attributes List, computed) (see [below for nested schema](#nestedatt--gsop_configs))
* `policies_non_cups_lte_config` (Attributes, computed) (see [below for nested schema](#nestedatt--policies_non_cups_lte_config))
* `site_name` (String, computed) - Name of the site where the node is deployed
* `traffic_source_configs` (Attributes List, computed) (see [below for nested schema](#nestedatt--traffic_source_configs))
* `vport_config` (Attributes, computed) - GigaSMART vPort (see [below for nested schema](#nestedatt--vport_config))
