# gigavuecore_load_mobility_user_node_configs Data Source

Load mobility user node configurations by alias

## Example Usage

```terraform
data "gigavuecore_load_mobility_user_node_configs" "example" {
  solution_alias = null
  upnode_alias = null
}
```

## Schema

### Arguments

The following arguments are supported:

* `solution_alias` (String, required) - Alias of the configured solution
* `upnode_alias` (String, required) - Alias of the user node
